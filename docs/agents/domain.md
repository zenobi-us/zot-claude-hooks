# Domain Docs

This is a single-context project.

Before exploring a topic, read these files when they exist:

- `CONTEXT.md` at the alignment root.
- `docs/adr/` for relevant architecture decisions.

If these files do not exist, continue without creating them. Create them only when domain terms or decisions require them.

Use the terms defined in `CONTEXT.md`. If a term is missing, record the gap and resolve it before introducing a new shared term.
